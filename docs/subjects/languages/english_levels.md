# Английский язык: Уровни A1 до C1 (Шпаргалки)

## Шкала уровней (CEFR)

| Уровень | Описание | Основной фокус |
| :---: | :--- | :--- |
| **A1** | Beginner (Начальный) | Базовые фразы, представление себя, простые вопросы. |
| **A2** | Elementary (Элементарный) | Общение на знакомые бытовые темы, описание прошлого. |
| **B1** | Intermediate (Средний) | Понимание сути в типовых ситуациях (работа, досуг, поездки). |
| **B2** | Upper-Intermediate (Выше среднего) | Свободное общение с носителями, понимание сложных текстов. |
| **C1** | Advanced (Продвинутый) | Беглое и спонтанное выражение мыслей в любых сферах. |
| **C2** | Proficiency (Владение в совершенстве)| Близок к носителю, понимание практически всего. |

## Шпаргалка: Времена (A2 - B1)

### Present Simple (Настоящее простое)
- **Использование:** Регулярные действия, факты, расписания.
- **Формула:** `I/You/We/They + V1`, `He/She/It + V1(-s/-es)`
- *Пример:* I study English every day.

### Past Simple (Прошедшее простое)
- **Использование:** Завершенные действия в прошлом.
- **Формула:** `V + -ed` (или вторая форма неправильного глагола)
- *Пример:* I went to the store yesterday.

### Present Continuous (Настоящее длительное)
- **Использование:** Действия происходящие прямо сейчас, в момент речи.
- **Формула:** `am/is/are + V(-ing)`
- *Пример:* She is reading a book now.

## Лексическая таблица: Замена базовых слов (B2-C1)
Чтобы ваша речь звучала более естественно и профессионально, старайтесь использовать синонимы.

| Базовое слово (A1-A2) | Продвинутый синоним (B2-C1) | Пример использования |
| :--- | :--- | :--- |
| **Very good** | Excellent, Superb, Outstanding | The presentation was *outstanding*. |
| **Very bad** | Awful, Terrible, Atrocious | The weather yesterday was *atrocious*. |
| **Important** | Crucial, Vital, Essential | It is *crucial* to understand this grammar rule. |
| **Hard** | Challenging, Demanding | He is currently facing a *challenging* task. |
| **Think** | Consider, Believe, Ponder | I highly *believe* that this is the best approach. |
